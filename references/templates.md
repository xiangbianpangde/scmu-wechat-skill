## 一、 微信标题五大创作公式（民大专属范式）

针对每次推文任务，Skill 应结合推文类型输出 **3 至 5 组** 不同风格的标题备选：

| 标题类型 | 标题设计公式 | 示范样例 |
| :--- | :--- | :--- |
| **公式一：悬念驱动式** | `[反常识/神秘亮点] + [民大地标或人物] + 揭秘/探寻？` | 全国第一！中南民大这栋神秘大楼，到底藏着什么宝藏？ |
| **公式二：情感共鸣式** | `[具体时令/地标动作] + [唤醒青春记忆或归属感]？` | 今晚南湖畔的落日与晚风，是不是也吹进了你的心底？ |
| **公式三：硬核榜样式** | `[顶尖成果/高光数字]！[民大青年身份]：[一句励志金句]！` | 保研名校、拿下国家级金奖！这位民大姑娘的秘诀，只有这四个字！ |
| **公式四：权威振奋式** | `重磅！/ 祝贺！中南民族大学[重大项目/突破/会议]……` | 喜报！中南民族大学入选国家级重大科研攻关团队！ |
| **公式五：诗意风物式** | `[节气/诗意物候]：在民大，把[季节]写成一封长信` | 霜落双塔，初冬已至：在民大，收藏专属你的那一抹暖意 |
