# 中南民族大学校情概况与视觉规范 (SCMU Profile & Visual Guide)

本参考文档系统梳理中南民族大学（South-Central Minzu University）的核心校情、标志性文化意象、学院组织规范及官方新媒体视觉识别系统，为公众号推文提供准确、生动、规范的文化背景与视觉支撑。

---

## 1. 学校基础信息与法理渊源

- **中文全称**：中南民族大学
- **中文规范简称**：中南民大（公文与新闻中严禁使用“民院”或历史曾用名“中南民族学院”，历史回顾栏目除外）
- **英文名称**：South-Central Minzu University
- **英文简称**：SCMU
- **创办时间**：1951年
- **办学性质**：国家民族事务委员会（国家民委）直属综合性普通高等院校，国家民委、教育部、湖北省人民政府、武汉市人民政府共建高校。
- **地理位置**：湖北省武汉市洪山区民族大道182号（坐落于光谷腹地、风景秀美的武昌南湖之滨）。
- **校训**：**笃信好学 自然宽和**
  - “笃信好学”：语出《论语·泰伯》，强调对信仰的坚定追求与对学术学问的刻苦钻研。
  - “自然宽和”：体现人与自然、人与社会、各民族师生之间的和谐共融与豁达包容。
- **办学方向与核心主线**：紧紧围绕**铸牢中华民族共同体意识**主线，全面贯彻党的教育方针和民族政策。

## 4. 微信公众平台视觉配色规范（SCMU Visual Palette）

推文排版推荐采用民大专属新媒体色彩体系，提升视觉专业度与品牌识别度：

```
[民大石榴红] #B8242A  ──── 核心主色：主标题、重点强调框、徽标卡片、节庆喜报
[南湖碧波蓝] #1F5F8B  ──── 辅助主色：学术资讯、官方要闻、理性卡片底纹、湖水意象
[晨曦暖金]   #D4A359  ──── 点缀色彩：获奖荣誉、金句高亮、星级提示、重点数字
[水墨炭黑]   #2D3142  ──── 正文字色：段落正文文本，清晰柔和，不伤视力
[素净浅灰]   #F8F9FA  ──── 背景衬色：引用文本框背景、代码块背景、表格隔行底色
[分界轻灰]   #E5E7EB  ──── 分割线：段落分割线、卡片边框浅色勾边
```

### 推荐文字排版参数
- **正文字号**：`15px` 或 `15.5px`（移动端阅读最舒适区间，兼顾年轻学生与教职工）
- **字间距（letter-spacing）**：`1.5px`
- **行间距（line-height）**：`1.75` ~ `1.85`
- **两端对齐**：微信排版必须开启两端对齐（`text-align: justify`）
- **段间距**：段落之间空一行，避免密集成堆的大段文字
